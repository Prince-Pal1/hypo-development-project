The Phase 0 Audit

This observatory visualizes the raw parameter optimization data from our Walk-Forward Evaluation.

During Phase 0, we discovered that the Dynamic Programming (DP) policy never switched parameters a single time.

The switching penalty λ tuned via nested CV correctly identified that trailing 10-day look-backs are too noisy to justify jumping between parameters.

The Oracle Gap

A rigorous permutation test established that an Oracle built on pure noise only yields a gap of 2.17 Sharpe.

Our true Oracle Gap is 2.336 Sharpe, mathematically surviving the permutation. This proves that while reactive trailing adaptation fails, predictive forecasting possesses genuine alpha.
